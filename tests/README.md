# Тесты LightRead

Автотесты работают в offscreen-режиме, не открывают модальные диалоги и не требуют установленных шрифтов.

## Запуск

Из корня проекта:

```bash
python -m unittest discover -s tests -v
```

Коротко:

```bash
python -m unittest discover -s tests
```

## Что покрыто

- **TestFormats** — парсинг FB2 / TXT / HTML, оглавление и текст глав.
- **TestLibrary** — прогресс и статусы, ручные метаданные (защита от сканера), метки, закладки, заметки, статистика.
- **TestThemes** — контраст всех тем, алиасы старых названий, палитра обвязки, кэш шрифтов.
- **TestUI** — библиотека (сетка/список, поиск), плашка «Продолжить чтение», карточка книги, метки, окно статистики.
- **TestReader** — открытие и навигация, поиск, закладки/подсветки, глобальная смена темы, яркость, несколько окон.
- **test_deep.py** — глубокие проверки: PDF (рендер, обрезка полей, миниатюры), EPUB/DOCX TOC, кэши глав и поиска, смещения поиска, стресс (40 книг, 5 окон), крайние случаи (битые файлы, дубликаты, unicode, бэкап), регрессии.
- **test_features.py** — новые возможности: расширенный Markdown и мягкие переносы, дедупликация по хэшу, умные коллекции, WebDAV round-trip, разбор OPDS и GitHub Releases, главный экран и базовые вкладки, группы вкладок, toast, редактор заметок, черновики, целостность БД, FTS5, hover-действия, скрытые сетевые пункты, разделённость и контраст палитры, форматирование DOCX, обложка по титульной странице, PPTX/ODP и реестр презентационных форматов, диалог свойств файла, текстовый fallback для старых DOC/PPT.

Дополнительные smoke-скрипты (PDF/EPUB/DOCX, TTS, словарь, полный цикл чтения) находятся во временной папке и запускаются вручную.
