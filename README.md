# LightRead

LightRead — кроссплатформенная читалка электронных книг на **PySide6 / Qt 6** с собственным дизайн-языком, браузерными вкладками, библиотекой, заметками, TTS, PDF-режимом и синхронизацией через WebDAV.

Проект ориентирован на локальную работу: данные хранятся на компьютере пользователя, телеметрии нет. Сеть используется только если вы явно настроили OPDS-каталог, WebDAV или проверку обновлений.

## Возможности

- **Чтение**: FB2, EPUB, TXT, HTML, DOCX, ODT, PDF и другие форматы; постраничный и свитковый режим, 1–2 колонки, настройки шрифта/интерлиньяжа/полей/яркости, темы «Светлая» и «Тёмная» с отдельными уровнями поверхностей и границ, акцентный цвет, мягкие переносы.
- **PDF/сканы**: рендер первой страницы как обложки, центрирование страниц, обрезка полей, инверсия в тёмной теме, масштаб, тени, быстрый переход между страницами без мигания.
- **Библиотека**: выбор папки с рекурсивным сканированием, отслеживание изменений на диске (`QFileSystemWatcher`), дедупликация по хэшу, сетка/список, сортировка, фильтры, метки, коллекции, умные коллекции, массовые операции, полнотекстовый поиск по названию/автору/аннотации/заметкам, диалог «Свойства файла» с путём, размером, датами и метаданными.
- **Главный экран и вкладки**: экран «Продолжить чтение» с недавними книгами и целью чтения; вкладки как в браузере — главная и библиотека без крестиков, кнопка `+`, `Ctrl+Tab`, `Ctrl+1…9`, `Alt+←/→`, история, `Ctrl+Shift+T`, цветные группы с фильтрацией, восстановление сессии.
- **Заметки**: редактор в панели чтения, быстрая заметка по `Ctrl+Shift+N`, якоря, устойчивые к смене вёрстки, цветные маркеры на страницах PDF, единый экран «Все заметки», экспорт и WebDAV-синхронизация.
- **TTS**: озвучка через Qt TextToSpeech, индикатор текущего слова, предпросмотр следующих фрагментов и подсветка в тексте.
- **Локальная надёжность**: проверка целостности БД с backup при повреждении, автосохранение черновиков заметок, полнотекстовый поиск FTS5, кликабельные действия на карточках при наведении.
- **Интеграции (скрыты по умолчанию)**: OPDS-каталоги (Atom), WebDAV, проверка обновлений через GitHub Releases API, словари StarDict. Включаются в `Настройки → Сервисы → Показывать сетевые функции`.
- **Интерфейс**: дизайн-система из трёх уровней токенов (primitive → semantic → chrome), адаптивная вёрстка, fullscreen (`F11`), режим фокуса (`F10`), командная палитра (`Ctrl+K`).

## Поддерживаемые форматы

`azw`, `azw3`, `cb7`, `cbr`, `cbt`, `cbz`, `chm`, `djv`, `djvu`, `doc`, `docm`, `docx`, `dotx`, `epub`, `fb2`, `fb3`, `fbz`, `htm`, `html`, `log`, `md`, `mobi`, `odp`, `odt`, `otp`, `ott`, `pdb`, `pdf`, `pps`, `ppsx`, `ppt`, `pptx`, `potx`, `prc`, `rar`, `rtf`, `text`, `txt`, `xhtml`, `zip`.

Для некоторых форматов нужны внешние утилиты:

| Формат | Требование |
|---|---|
| DJVU | `ddjvu` из DjVuLibre |
| DOC | `antiword`, `catdoc` или LibreOffice |
| CHM | `7z` / `7za` (на Windows — `hh.exe`) |
| CBR/CB7/CBT, RAR | `7z` / UnRAR |
| PPT/PPS (legacy) | LibreOffice для точного рендера; без него — встроенный текстовый fallback |
| DOC (legacy) | LibreOffice/antiword для точного текста; без них — встроенный текстовый fallback |
| Точная обложка DOCX/ODT/PPTX/ODP | LibreOffice или Word (иначе используется встроенный рендер титула) |
| AZW3 / HUFF-CDIC | опциональный пакет Python `mobi` |

## Быстрый старт

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python main.py
```

Открыть книгу можно через `Файл → Открыть файл…`, перетащив файл в окно или передав путь аргументом:

```bash
python main.py "/path/to/book.epub"
```

### Portable-режим

Если рядом с исполняемым файлом создать `portable.txt` или `portable.ini`, база данных, обложки и настройки будут храниться в папке `data/` рядом с приложением.

Иначе данные хранятся в:

- Windows: `%APPDATA%\LightRead`
- Linux: `$XDG_CONFIG_HOME/LightRead` или `~/.config/LightRead`
- macOS: `~/Library/Application Support/LightRead`

## Сборка

Готовые скрипты лежат в корне репозитория:

```bat
build-win.bat
```

```bash
bash build-linux.sh
```

Сборка использует PyInstaller и явно подключает `QtPdf` и `QtTextToSpeech`, чтобы избежать «сборки без PDF/TTS».

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты работают в offscreen-режиме, не открывают модальные диалоги и не требуют установленных шрифтов. Подробнее — [tests/README.md](tests/README.md).

## Архитектура

| Файл | Ответственность |
|---|---|
| `common.py` | пути, настройки, темы и токены дизайн-системы (primitive → semantic → chrome) |
| `theming.py` | применение токенов к QSS и QPalette |
| `ui.py` | библиотека, вкладки, диалоги, `BookDelegate`, сканер |
| `reader.py` | окно чтения, панель настройки, TTS, закладки и заметки |
| `views.py` | рендер reflow-текста и PDF, оптимизированный вывод страниц |
| `formats.py` | парсеры и единая модель `Source` → `Chapter` |
| `library.py` | SQLite-хранилище книг, меток, закладок, заметок и статистики |
| `services.py` | TTS, StarDict, OPDS, WebDAV, проверка обновлений |
| `main.py` | точка входа, single-instance и ассоциации файлов |

## Известные ограничения

- У сканов без OCR-текстового слоя поиск по содержимому страниц невозможен. Доступен поиск по закладкам оглавления.
- Точность позиции слова в TTS ограничена движком Qt: подсветка слова рассчитывается по длине слова и скорости озвучки.
- Мягкие переносы применяются только к текстовым книгам и включаются в настройках.
