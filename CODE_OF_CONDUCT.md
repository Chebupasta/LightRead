# Кодекс поведения

## Наше обязательство

Мы хотим, чтобы участие в LightRead было безопасным и комфортным для всех независимо от опыта, происхождения, языка, идентичности и убеждений.

## Ожидаемое поведение

- Уважайте других участников и их точки зрения.
- Давайте конструктивную обратную связь по коду и идеям, а не по людям.
- Признавайте ошибки и помогайте их исправлять.
- Используйте понятный и дружелюбный тон.

## Недопустимое поведение

- Оскорбления, дискриминация, преследование и публичные «личные» нападки.
- Размещение чужих приватных данных без согласия.
- Умышленный вандализм в репозитории, трекере задач или обсуждениях.
- Публикация уязвимостей вместо приватного сообщения (см. [SECURITY.md](SECURITY.md)).

## Применение

Нарушения можно сообщить через приватный канал GitHub Security или напрямую мейнтейнерам через GitHub. Сообщения рассматриваются конфиденциально. За нарушения может последовать предупреждение, блокировка или запрет на участие.
